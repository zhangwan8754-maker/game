# INK RUSH 2v2 · 手机涂地对战

在浏览器里玩的 **2v2 涂地射击游戏**：手机横过来就能玩，不用装 App。一个人建房间，把链接或房间码发给朋友，4 个人就能一起打。

两队各 2 人，在一局 3 分钟里用墨水涂地面。时间到时，**地面涂得多的一队获胜**。人不够的话，空位由机器人补上。

> 本项目基于 [hwkim3330/ink-rush](https://github.com/hwkim3330/ink-rush)（MIT 许可证）改造。原作是电脑上用键鼠玩的 4v4 版本，这里改成了 2v2，并加上了手机触屏操作和中文界面。原作的版权声明保留在 [LICENSE](LICENSE) 里。

## 怎么和朋友一起玩

1. 用手机浏览器打开游戏网址（部署方法见下文），直接进游戏，**手机横着拿**。手机开了方向锁定、或者浏览器（比如微信）不跟着转屏也没关系：游戏画面会自己转 90°，手机向左横过来拿就是正的。
2. 一个人点 **和朋友联机 → 创建房间**，会得到一个 5 位房间码和一个链接。
3. 把链接发到微信群，或者让朋友在「加入朋友的房间」里输入房间码。
4. 人到齐后（最多 4 人，可以点「换队」调整队伍），房主点 **开始**。

**网络建议**：
- 最稳的方式是**大家连同一个 Wi-Fi**，或者一个人开热点让其他人连。
- 游戏是玩家之间直连的，房主的手机负责运行整局游戏。不同网络之间（比如 4G 连家里宽带）有时打不通，打不通就换到同一个 Wi-Fi 再试。
- 在**微信里**打开链接时，先点右上角的「在浏览器打开」，用系统浏览器玩最稳。
- 房主不要切到后台或锁屏，否则其他人会掉线。

## 手机操作

| 操作 | 作用 |
|---|---|
| 左半屏拖动 | 移动。手指按在哪里，摇杆就出现在哪里 |
| 右半屏拖动 | 转视角 / 瞄准 |
| **开火**（按住） | 射击。按住开火时继续拖动，可以边打边瞄 |
| **潜游**（点一下切换） | 潜进自己颜色的墨里：游得快、敌人看不见、墨水回得快。开火会自动浮出来 |
| **跳** | 跳跃（潜游时跳得更高） |
| **炸弹** | 扔墨水炸弹，耗掉大半罐墨 |
| **大招**（右上角圆圈） | 涂地攒满能量后按：跳起来炸开一大圈 |

主菜单里可以调**视角灵敏度**、**上下反转**、**辅助瞄准**（开火时准星会轻微吸附附近的敌人），以及**画质**：手机发烫或卡顿就选「流畅」。

三种武器：**速射枪**（连发、最好上手）、**滚筒**（按住滚地碾人，点一下甩墨）、**蓄力狙**（按住蓄力，蓄满一枪击倒）。

电脑上也能玩：WASD 移动、鼠标瞄准、左键开火、Shift 潜游、空格跳、右键或 E 扔炸弹、Q 放大招。

## 部署到 GitHub Pages（免费网址）

仓库里已经带了自动部署的 GitHub Actions 配置（`.github/workflows/pages.yml`），推到 `main` 分支就会自动构建并发布。第一次需要手动开启：

1. 把这个分支合并到 `main`。
2. 打开仓库的 **Settings → Pages**，「Build and deployment」下的 Source 选 **GitHub Actions**。
3. 到 **Actions** 页面等 “Deploy to GitHub Pages” 跑完，网址是 `https://<你的用户名>.github.io/<仓库名>/`。

## 本地运行

需要 Node.js 22 和 pnpm。

```bash
pnpm install
```

```bash
pnpm dev --host
```

终端里会显示一个局域网地址（例如 `http://192.168.1.5:5421`）。同一个 Wi-Fi 下的手机用浏览器打开这个地址就能玩。

## 国内联机连不上怎么办

联机需要一个「中介服务器」帮玩家互相找到对方。找到之后，游戏数据是玩家之间直连的，不经过它。默认用的是 PeerJS 的免费公共服务器 `0.peerjs.com`，它在国外，国内有可能连不上或者很慢。连不上时，房主建房间会提示「联机中介服务器出错」。

解决办法是在一台国内云服务器上自己跑一个中介服务器：

```bash
npx peer --port 9000
```

然后给它配一个 HTTPS 域名（用 nginx 反向代理，并支持 WebSocket）。GitHub Pages 是 HTTPS 网页，只能连 `wss://` 地址。有两种方式让游戏用它：

- **不用重新部署**：在游戏网址后面加上 `?broker=wss://你的域名/`，用这个网址建房间。游戏分享出去的房间链接会自动带上这个参数。
- **改成默认**：在仓库的 **Settings → Secrets and variables → Actions → Variables** 里添加变量 `PEER_HOST`（你的域名），按需再加 `PEER_PORT`（默认 443）、`PEER_PATH`（默认 `/`）、`PEER_KEY`（默认 `peerjs`），然后重新部署。

如果不同网络之间（4G 和宽带）经常直连失败，可以再架一个 TURN 中转服务器（比如 coturn），把它写进变量 `ICE_SERVERS`，格式是 JSON 数组，例如：

```json
[{"urls":"stun:stun.miwifi.com:3478"},{"urls":"turn:你的域名:3478","username":"user","credential":"pass"}]
```

## 测试

`tools/` 里有用 Playwright 模拟手机做的自动测试：

- `tools/phone.mjs`：模拟手机和机器人对战，全程用触屏操作。浏览器横屏、浏览器竖屏（游戏自己转 90°）各跑一遍，检查摇杆方向、转视角方向、开火、边打边瞄、潜游、结算和再来一局。
- `tools/phone-online.mjs`：模拟 4 台手机进同一个 2v2 房间。检查第 5 个人会被拒绝，以及 4 台手机上的涂地格数和胜负结果完全一致。

```bash
pnpm build
```

```bash
pnpm preview
```

```bash
pnpm test:phone
```

联机测试需要一个本地中介服务器：

```bash
npx peer --port 9000 --host 127.0.0.1
```

```bash
pnpm test:online "http://127.0.0.1:5420/?broker=ws://127.0.0.1:9000/"
```

如果 Playwright 找不到浏览器，用环境变量 `PW_CHROMIUM` 指定 Chromium 的路径。

## 相对原版的改动

- **2v2**：每队 2 人，一个房间最多 4 人，空位由机器人补。新增 2v2 专用小地图「天台球场」，原来的两张大地图也还能选。
- **手机触屏操作**：浮动摇杆、拖动瞄准、开火 / 潜游 / 跳 / 炸弹 / 大招按钮，支持多指同时操作；手机上可选辅助瞄准。
- **手机适配**：横屏布局；浏览器停在竖屏时（方向锁定、微信内置浏览器）游戏画面自动转 90°，不用等浏览器转屏；安卓上自动全屏；刘海屏安全区；开始 / 返回按钮固定在卡片底部；画质三档可选。
- **中文界面**。
- **国内网络**：加了国内能连的 STUN 服务器（`stun.miwifi.com`）。中介服务器和 TURN 服务器可以配置。Google 字体改成不阻塞页面加载，国内打不开 Google 也不会白屏。
